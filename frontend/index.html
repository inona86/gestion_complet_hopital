Comment démarrer ?

L'application est prête à l'emploi. Voici les étapes pour lancer MediBase.

1

Configurer la base de données MySQL

Assurez-vous que MySQL est en cours d'exécution et que la base de données medibase est créée avec les tables requises. Les paramètres de connexion sont dans backend/db.js.

2

Lancer le serveur backend

Dans le dossier backend/, exécutez npm install puis node server.js. Ou utilisez le script start.sh (Linux/Mac) ou start.bat (Windows). Le serveur démarre sur le port 3000.

3

Accéder à l'application

Ouvrez votre navigateur et accédez à http://localhost:3000. Le tableau de bord MediBase s'affiche avec la connexion MySQL active.

4

Commencer à gérer vos données

Utilisez la navigation latérale pour accéder aux différents modules. Ajoutez, modifiez et supprimez des enregistrements directement depuis l'interface. Les modifications sont instantanément sauvegardées dans MySQL.
